# Ícones de tecnologias

Arquivos locais obtidos do [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), distribuído sob licença MIT, reproduzida em LICENSE-devicon.txt. Os nomes dos arquivos correspondem aos diretórios de origem. Variantes original, com desenhos e cores preservados da distribuição.

SQL utiliza o ícone genérico database do [Bootstrap Icons v1.11.3](https://github.com/twbs/icons/blob/v1.11.3/icons/database.svg), sob licença MIT, reproduzida em LICENSE-bootstrap-icons.txt.

SQL mantém o desenho genérico de banco de dados em cinza neutro (#B8B8BF), pois não representa uma marca específica. As marcas pertencem aos respectivos titulares; sua exibição identifica as tecnologias utilizadas.
